# Security Policy

## Supported Versions

This project is pre-1.0. Security fixes target the latest commit on `main`.

## Reporting a Vulnerability

Please report vulnerabilities through GitHub Security Advisories for this repository. If a public issue is the only available path, avoid sharing exploit details until the issue can be handled privately.

## Scope

Security-sensitive areas include plugin tool schemas, lifecycle hooks, test helpers, and any code that could affect how OpenClaw runtimes validate or execute plugin behavior.
